# Dreamina prompts for "In Alexander's Sandals"

The game finds clips by itself. Save each clip in a folder called `media` next to `alexander_choices.html`, using the file name shown below (for example `media/granicus.mp4`). A `.jpg` or `.png` image with the same name works too. If a scene has no file, the game shows an emoji picture instead.

**Style line to add to the end of every prompt, so all the scenes look alike:**
> Painterly illustrated storybook style, warm golden light, cinematic wide shot, slow gentle camera movement, ancient Greek and Persian 4th century BC costume, suitable for 10-year-old students, no blood or gore, no text.

**Recurring characters (describe them the same way every time):**
- **Alexander**: young Macedonian man with wavy shoulder-length light-brown hair, clean-shaven, bronze muscle cuirass, red cloak, white-plumed helmet in battle.
- **Bucephalus**: huge black stallion with a white star on his forehead.
- **Darius III**: Persian king with a tall crown, long curled black beard, purple and gold robes, golden chariot.
- **Porus**: very tall Indian king in white and gold, riding a large armoured war elephant.
